        How to play

        1. Pick a skill slot (click it or press 1–5). Its glyph appears as an outline on the sigil pad, with its stroke order playing.
        2. Trace the glyph inside the outline. Tap above it for a kudlit -i, below for -u, or nothing for -a. Each changes the spell.
        3. Cast with Enter. Accuracy and speed set the power; the slot then recharges.
        4. Read the Aswang. Its glyph floats above it before each spell lands. Raise a shield, or stun / knock it back to interrupt.
        5. Master the glyphs. Clean casts fade the outline; casting from memory hits up to ×1.45 harder.
